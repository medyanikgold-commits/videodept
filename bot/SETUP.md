# Запуск бота видеоотдела на DigitalOcean

## Что подготовить (10 минут, с телефона)

1. **Новый бот.** В Telegram открой @BotFather → `/newbot` → придумай имя. Скопируй токен вида `123456:ABC...`.
   Нужен именно новый бот: твой текущий бот продолжит работать как раньше.
2. **Твой ID.** Напиши @userinfobot, он ответит числом, это твой ID.
3. **Ключ Claude API.** console.anthropic.com → API Keys → Create Key. Пополни баланс на 5 $, этого хватит примерно на месяц.
4. **(Необязательно) Telegram-канал** для публикации: добавь нового бота в админы канала.

## Сервер

1. cloud.digitalocean.com → **Create → Droplets**.
2. Образ: **Ubuntu 24.04**. Тариф: **Basic, Regular, 2 GB / 1 CPU** (около 12 $ в месяц). Регион: Frankfurt или Amsterdam.
3. Создай, открой droplet → кнопка **Console** (откроется чёрное окно прямо в браузере).
4. Вставь одну команду и ответь на 3 вопроса: токен, ID, ключ.

```
curl -sL https://raw.githubusercontent.com/medyanikgold-commits/videodept/main/bot/install.sh | REPO_URL=https://github.com/medyanikgold-commits/videodept bash
```

Когда увидишь «Готово! Напиши своему боту /start», открой бота в Telegram и нажми Start.

## Как пользоваться

- **Свой ролик:** отправь боту клипы (можно альбомом). В подписи напиши кодовое слово, например `ПАНЕЛЬ`, можно с заголовком: `ПАНЕЛЬ | Панели прямо с завода`. Нажми «Смонтировать», и через несколько минут придёт готовый ролик с кнопками публикации.
- **ИИ-ролики** бот делает сам в 9:00 и 13:00 по Москве и присылает на одобрение. `/auto` включает публикацию без одобрения.
- `/panel` присылает ссылку на панель видеоотдела: видно, кто из помощников сейчас работает и что делает, очередь тем и журнал действий.
- `/ai тема` делает ролик сейчас, `/topics` показывает очередь тем, `/add тема` ставит тему первой.

Видео тяжелее 20 МБ обычный Telegram-бот не принимает: отправляй клипы как видео, а не файлом, Telegram их сожмёт.
Чтобы снять ограничение (до 2 ГБ), впиши в настройки `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` с my.telegram.org и запусти установку ещё раз.

## Если что-то не так

- Лог бота: `journalctl -u videobot -f`
- Поменять настройки (VK, канал, время роликов): `nano /opt/videodept/bot/.env`, потом `systemctl restart videobot`
- Обновить программы: запусти ту же команду установки ещё раз, настройки сохранятся.
