# Видеоотдел: товары из Китая

Две программы и бриф:

| Файл | Что делает |
|---|---|
| `automontage.py` | **Монтажёр твоих видео.** Склеивает клипы с телефона, вырезает паузы, делает вертикаль, субтитры с подсветкой слов, заголовок-крючок, надпись с кодовым словом, музыку. |
| `reels.py` | **ИИ-ролики без тебя.** Тема → сценарий (Claude) → голос → картинки → субтитры → готовое видео и текст поста. Умеет делать пачку роликов по списку тем. |
| `brand.md` | **Бриф.** Кто ты, что продаёшь, кому, каким тоном. Сценарист читает его перед каждым сценарием. Поменял бриф, значит поменялись все будущие сценарии. |
| `plans/` | Контент-план недели и список тем для ИИ-роликов. |

## Установка (один раз)

1. Python 3.10+ и ffmpeg (Windows: `winget install ffmpeg`, Mac: `brew install ffmpeg`).
2. В этой папке: `pip install -r requirements.txt`
3. Ключ Claude API с console.anthropic.com:
   - Windows: `setx ANTHROPIC_API_KEY "sk-ant-..."` и перезапустить терминал
   - Mac: `export ANTHROPIC_API_KEY="sk-ant-..."`

## Твои видео с телефона

```
python automontage.py fabrika1.mp4 fabrika2.mp4 --code ПАНЕЛЬ --ai
python automontage.py zavod.mp4 --title "Сколько стоит панель на заводе" --code ПАНЕЛЬ --music music.mp3
```

- `--code` это кодовое слово: в конце появится «Пиши «ПАНЕЛЬ» в комментариях».
- `--ai`: Claude придумает заголовок-крючок и текст поста с хэштегами (по расшифровке твоей речи).
- Клипы без речи (просто съёмка цеха) остаются целиком, паузы режутся только там, где ты говоришь.
- Первый запуск скачает модель распознавания речи (бесплатно, потом работает без интернета). Точнее, но медленнее: `--whisper medium`.

## ИИ-ролики

```
python reels.py --batch plans/week1_ai_topics.txt          # все темы недели разом
python reels.py --topic "Как работает карго из Китая"       # один ролик
python reels.py --script output/ролик.json                  # пересобрать после правки сценария
```

Голос: `--voice ru-RU-DmitryNeural` (мужской, по умолчанию) или `ru-RU-SvetlanaNeural`.
Свои фото вместо ИИ-картинок: `--images папка/` (файлы 1.jpg, 2.jpg, ...).

Всё готовое лежит в `output/`: видео `.mp4`, сценарий `.json` и текст поста `_post.txt`.
Если какой-то сервис недоступен, ролик всё равно соберётся: без голоса или с цветным фоном вместо картинки.
